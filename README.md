# Sistema preoperacional

Base inicial del aplicativo de preoperacional y FUEC para ARENAS Transporte.

## Rutas pensadas

- `app.arenastransporte.com` para la operacion interna
- `arenastransporte.com/validar/{codigo}` para validar documentos por QR

## Modulos iniciales

- login por roles
- panel conductor
- panel administrador
- formulario preoperacional
- verificacion publica por codigo

## Pasos cuando el entorno este listo

1. Instalar Node.js LTS
2. Ejecutar `npm install`
3. Configurar variables de entorno
4. Crear proyecto Supabase
5. Ejecutar el esquema SQL
6. Ejecutar `npm run dev`
